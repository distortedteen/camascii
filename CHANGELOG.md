## [1.0.0] - 2024-01-01

### Added

- Initial release
- 4 character sets: minimal, detailed, blocks (default), matrix
- edge-detect mode with Canny filter
- 256-color mode mapping RGB to xterm-256 colors
- adjustable Canny thresholds
- freeze + save frames as .txt
- invert & mirror controls
- audio-reactive mode (guitar edition)
- color themes: neon, amber, matrix, ghost, thermal, vhs
- CRT glitch effects
- frame recorder with .zip and video export
- overlay system (VU meter, title card, border, REC indicator)
